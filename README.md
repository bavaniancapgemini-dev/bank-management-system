# 🏦Bank Management System v8.0

A comprehensive Bank Management System developed using Python SQLite. This project simulates real-world operations include account amangement, transactions, loans, fixed deposits, customer profiles, credit scoring, fraud detection, ATM card management, analytics, and audit logging.

---

## 📌 Features

### Account Management
- Create Bank Account
- View All Accounts
- Search Account
- Delete Account
- Deposit Money
- Withdraw Money
- Transfer Money

### Customer Management
- Customer Registration
- Customer Login
- Customer Profiles
- Account Status Management
- Account Reset System

### Security Features
- Admin Login
- Role-Based Access Control
- OTP Verification
- Fraud Detection for Large Transactions
- Password Reset System

### Banking Operations
- Loan Management
- Fixed Deposit Management
- EMI Calculator
- Monthly Interest Processing
- ATM Card Issuing System

### Credit Services
- Credit Score Management
- Customer Credit Tracking

### Employee & Branch Management
- Add Employees
- View Employee
- Branch Management
- View Branch Information

### Analytics & Reports
- Banking Analytics Dashboard
- Advanced Analytics
- Richest Customer Reports
- Total Bank Balance Reports
- PDF Bank Generation
- JSON Data Export

### Audit System
- Transaction Logs
- Activity Logs
- Audit Trail Monitoring
